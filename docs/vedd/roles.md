# VEDD Roles

Every agent operates under exactly one active role.

Before acting:

1. Read `AGENTS.md`.
2. Identify your assigned role.
3. Read ONLY the corresponding file in `docs/vedd/roles/`.
4. Do not assume permissions from other roles.
5. Escalate rather than switching roles implicitly.
