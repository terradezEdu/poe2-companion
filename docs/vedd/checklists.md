# VEDD Checklists

---

# Definition of Ready

- [ ] Purpose is understood.
- [ ] Relevant visual intent exists.
- [ ] Important rules are clear.
- [ ] Material open questions are resolved.
- [ ] Dependencies are known.
- [ ] Expected behaviour is described.
- [ ] Important examples exist.
- [ ] Evidence level is known.
- [ ] Slice is small enough to integrate incrementally.

---

# Definition of Done

- [ ] Implementation exists.
- [ ] Approved acceptance behaviour passes.
- [ ] Affected contracts pass.
- [ ] Required unit tests pass.
- [ ] Required integration tests pass.
- [ ] Architecture fitness checks pass.
- [ ] Relevant static/security/performance checks pass.
- [ ] Visual result matches approved intent where applicable.
- [ ] No protected artifact was silently weakened.
- [ ] Spec remains aligned.
- [ ] Evidence summary exists.
- [ ] Remaining risks are explicit.

---

# Convergence trigger checklist

Run a convergence audit when one or more are true:

- [ ] Walking Skeleton completed.
- [ ] Core loop completed.
- [ ] Major feature cluster integrated.
- [ ] Large architecture change completed.
- [ ] Duplicate patterns are appearing.
- [ ] Dead code appears to be accumulating.
- [ ] Build/test times degrade significantly.
- [ ] Spec/code drift is suspected.
- [ ] Beta/release milestone approaches.
