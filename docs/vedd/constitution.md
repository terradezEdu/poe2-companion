POE2 COMPANION — CONSTITUTION

Purpose
-------
Help players understand campaign areas before entering them.

Primary user
------------
Path of Exile 2 players, with special support for Hardcore.

Core principles
---------------
- Information must be fast to consume while playing.
- Dangerous mechanics have priority over trivia.
- Data must be traceable to a source.
- Navigation should feel like an RPG campaign map.
- Do not reproduce GGG UI/assets pixel-perfect.
- Prefer local structured data initially.
- No backend in v0.x unless justified.

Engineering principles
----------------------
- Spec before implementation.
- Acceptance behavior is protected.
- One task = one worktree.
- Implementers cannot modify approved acceptance criteria.
- No automatic merges.
- Human reviews code before merge.
